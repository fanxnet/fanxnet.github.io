安装opencode
法1，sudo npm install -g opencode-ai@latest
法2，curl -fsSL https://opencode.ai/install | bash
升级
opencode upgrade

卸载 OpenCode 并删除所有相关文件。
opencode uninstall


使用
# Change directory into your codebase
配置进 ~/.local/share/opencode/auth.json录入密钥，～/.config/opencode/opencode.json配置只写 baseURL、
opencode auth list    # 查看已存所有服务商密钥
opencode auth remove deepseek  # 清空该服务商auth存储
opencode auth login --provider deepseek # 交互式重新录入密钥
cd /to/your/project
opencode # 默认模型登入
cpencode models # 显示可能模型，下面命令按指定模型登入
opencode --model google/gemini-flash-lite-latest
opencode --model deepseek/deepseek-v4-flash
#OpenCode TUI 启动后的主对话输入框,会话第一条指令可以是/sessions，也可 新主题,告诉 AI 你进来想做什么,完成会话上下文创建：
    读项目：梳理整个项目目录结构
    改代码：优化这个项目的配置文件
    查 bug：查找代码里报错的位置
/sessions #管理,选中session继续工作.
opencode -c # 启动等价opencode --continue 继续上一次会话，完全不用输任何内容
opencode session list #列出本机session
opencode -s 会话ID # 启动指定会话ID
 分叉会话（基于当前会话另开分支，不污染原对话）适合：想在现有对话基础上试改方案，又不想覆盖原有上下文
/fork
#初始化 OpenCode。
/init 生成项目 AGENTS.md
